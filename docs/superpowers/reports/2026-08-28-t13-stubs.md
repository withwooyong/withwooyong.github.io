## R51 — 「없다」가 아니라 **「측정 계층이 틀렸다」**

구현자가 블로커를 보고했다 — `robots` 메타 단언 6건이 타임아웃. 제시된 해법 셋은 전부
**프로덕션 동작이나 브리프를 바꾸는 것**이었다(`content="1"` 로 지연 / 서브리소스 추가 / 라우트 유지).

진짜 원인은 검사의 **측정 계층**이었다. `<meta name="robots">` 의 소비자는 **렌더러가 아니라 크롤러**이고
크롤러는 바이트를 읽는데, 검사는 브라우저로 DOM 을 폴링했다. `content="0"` 이 제 역할을 정확히 하는 바람에
읽기 전에 페이지가 떠난 것이다.

구현자의 관찰 중 결정적인 것은 이쪽이다 — **"wiki 스텁 6건이 통과하는 건 계약이 아니라 우연이다."**
Next 스텁은 스크립트 로딩이 ~25ms 를 벌어 폴링이 이겼을 뿐이다. **초록이던 6건도 타이밍이었다.**

`request.get()` + `<head>` 파싱으로 옮기니 9개가 **같은 근거로** 초록이 됐다. 실제 이동 여부는
위 describe 의 `waitForURL` 이 브라우저로 재고 있어 커버리지 손실이 없다 — **두 검사가 서로 다른 계층을 하나씩 맡는다.**

## R52 — `noindex` 는 뺐다. 같은 관례가 대상이 바뀌면서 무해에서 유해로 넘어갔다

계획서와 `public/notion/index.html` 선례는 둘 다 `noindex, follow` + canonical 을 쓴다.
접근성 축이 이것을 HIGH 로 지적했고, **사용자가 `noindex` 제거를 결정했다.**

| | `/notion/` | T13 스텁 9개 |
| --- | --- | --- |
| canonical 대상 | **외부** Notion 사이트 | **`/work/`** — 포트폴리오에서 색인이 가장 중요한 페이지 |
| `noindex` 가 클러스터로 전파되면 | 잃을 것 없음 | **`/work/` 가 색인에서 빠진다** |

구글은 canonical 로 묶인 URL 무리를 하나로 취급하므로 무리 안의 `noindex` 가 대표 URL 까지 끌어내릴 수 있다.
중복 제거는 canonical 하나로 충분하고, 검색엔진 노출 차단은 `sitemap` 의 `EXCLUDE` 가 맡는다.

**선례가 있다는 것이 그 선례를 따라야 한다는 뜻은 아니다** — 위험도가 무엇에 달려 있는지를 봐야 한다.
`redirects.spec.ts` 에 그 근거를 주석으로 박아 「선례대로 되돌리는」 회귀를 막았다.

## R53 — 뮤테이션이 **리뷰어 3명이 전부 놓친 것 2건**을 잡았다

1차 판정 **8/10 사멸, 2 생존.** 둘 다 진짜였고 둘 다 「초록인데 계약이 안 지켜지는」 모양이다.

| 생존 | 무엇이 뚫렸나 | 왜 리뷰가 못 잡았나 |
| --- | --- | --- |
| **#1** | `meta http-equiv="refresh"` 를 재는 단언이 **아예 없었다.** 주석은 「바이트에서 잰다」고 3/3 실측까지 적어 놨는데 `test()` 는 robots·canonical 만 쟀다. `waitForURL` 은 스텁의 `location.replace()` 가 대신 만족시켜 초록 유지 | **주석이 단언처럼 보인다.** 실측 수치가 붙어 있어 오히려 가장 검증된 자리로 읽혔다 |
| **#6** | `data-pagefind-ignore` 단언이 **속성이 아니라 HTML 주석**에 걸렸다. 속성을 지워도 `</head>` 뒤 설명 주석이 정규식을 만족 | `bodyOf()` 는 `__NEXT_DATA__` 거짓 양성을 막으려고 만든 헬퍼인데 **자기가 쓴 설명 주석**에 걸렸다 |

#1 은 **주 경로가 무방비였다.** JS 가 도는 브라우저에서는 `location.replace()` 가 덮지만,
크롤러와 JS 를 끈 사용자에게는 `meta refresh` 가 전부다.

수정 후 두 뮤턴트를 재주입해 **4 failed (2 논리 검사 × 2 프로젝트)** 로 사멸을 확인했다 — **최종 10/10.**

**읽어서 잡을 수 있었으면 리뷰어 3명 중 하나는 잡았다.** 코드를 망가뜨려 보는 것만이 이 둘을 갈랐다.

### #11 — 새 대상 2개는 서로 독립이 아니다

`site-shell.tsx` 의 `tabIndex={-1}` 뮤턴트 하나가 `/work/`·`/about/` **2건을 함께** 죽였다.

**주석은 단언이 못 되지만, 잃은 것을 기록하는 데는 여전히 유일한 수단이다.**

### ⑦ 편1 — 신규 도식이 원본에 없는 되먹임 고리를 닫는다 [실측]

| | |
| --- | --- |
| **위치** | `reversibility-before-permission.md:60-69` (mermaid + 해설) |
| **발행본** | `A["자동화 효용"] --> R["복구 지점 밀도"]` 및 L69 「**이 순환에서** 사람이 직접 돌릴 수 있는 손잡이는 맨 왼쪽 하나뿐」 |
| **원본** | `01` L542~544 = 「롤백 지점이 촘촘할수록 넓은 권한 → 권한이 넓을수록 자동화 효용이 커진다」 — **단방향 사슬 R→P→A.** 역방향 A→R은 없다 |
| **확신도** | **[실측]** |

도식 2개는 §4-2가 승인한 추가물이지만 **그 안에 그린 화살표 하나가 원본에 없는 주장**이다.
부수적으로 도식 자체도 정합하지 않는다 — `R --> C`(밀도↑ → 비용↓)는 무라벨 양의 화살표인데 `C -->|"높으면"| N`만 조건 라벨이 붙어, 같은 노드에서 나가는 두 화살표의 의미가 다르다.

근거로 삼은 `01 §11-1`은 **면접 절**이라 설계서상 Q&A(B8) 몫이다. 개념이 §6-1과 겹치므로 유출로 판정하지는 않으나, 표현(「복구 가능성의 함수」 → 「복구 비용의 함수」)이 §11 L527에서 왔을 가능성이 높다.

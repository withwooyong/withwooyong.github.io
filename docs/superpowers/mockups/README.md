## 목업과 스펙이 어긋날 때

**스펙이 정본이다.** 목업은 스펙보다 먼저 만들어졌고, 이후 실측으로 뒤집힌 결정
(홈서버·`/notes` 경로·Ask 챗봇)이 목업에는 반영되지 않았다. 폐기된 결정은
설계 문서 부록 B를 본다.

목업이 값을 하는 곳은 **디자인 판단**이다 — 색 램프의 층이 실제로 보이는지,
히어로 연출의 속도가 어떤지는 글로 확인할 수 없다. 단계 1~2에서 이 파일들을
열어 놓고 작업한다.

대안 — 모바일 기본을 목록으로 두고 그래프는 탭 전환. 3D 번들을 아예 안 받아 가장 빠르지만, 첫인상의 임팩트를 포기합니다.

A

모바일도 그래프 우선

폰에서도 첫 화면은 그래프. 노드 수를 줄이고 2D 경량 렌더러로 강등합니다.

B

모바일은 목록 우선

폰 기본은 목록, 그래프는 탭으로. 성능이 가장 안전합니다.

C

기기 성능으로 자동 결정

코어 수·메모리·저전력 모드를 보고 그래프/목록을 자동 선택. 사용자는 언제든 수동 전환.

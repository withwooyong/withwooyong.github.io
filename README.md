# 우용의 포트폴리오

개발자 우용의 포트폴리오 웹사이트입니다.

## 기술 스택

- **Frontend**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages

## 로컬 개발 환경 설정

1. 의존성 설치

```bash
npm install
```

2. 개발 서버 실행

```bash
npm run dev
```

3. 브라우저에서 [http://localhost:3000](http://localhost:3000) 열기

## 빌드 및 배포

1. 프로덕션 빌드

```bash
npm run build
```

2. 정적 파일 생성

```bash
npm run export
```

3. `out` 폴더의 내용을 GitHub Pages에 배포

## 프로젝트 구조

```
├── pages/           # Next.js 페이지
├── styles/          # CSS 스타일
├── public/          # 정적 파일
└── components/      # React 컴포넌트
```
